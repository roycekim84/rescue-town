# Rescue Town

> 구조한 동물들이 주민이 되고, 주민들이 스스로 살아가며 성장시키는 작은 마을.

모바일 2D 경영/생활 시뮬레이션 프로젝트.

## 핵심 방향
- 시작은 매우 단순하고, 깊게 플레이할수록 시스템의 연결이 드러난다.
- 구조한 동물은 수집품/직원이 아니라 마을에서 삶을 이어가는 주민이다.
- 직접 돌봄에서 시작해 자동화와 마을 경영으로 플레이어의 역할이 변화한다.
- 광고 수익화를 기본 전제로 하되 기본 플레이를 광고가 막지 않는다.

## v1.0
첫 출시는 **시골 마을 하나**의 완성을 목표로 한다.
지역 이동과 후속 지역은 v1.0 범위 밖이며 현재 기획하지 않는다.
