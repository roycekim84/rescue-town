## 계정·권한 확인 목록
아래는 모두 소유자 환경에서 확인할 항목이며 현재 미확인이다. 비밀값을 이 문서에 적지 않는다.
- Unity 라이선스/설치경로와 정식6000.3패치.
- Mac Xcode/iOS 서명·테스트기기, Android SDK/NDK/기기.
- 최종 패키지/번들ID와 앱 이름.
- AdMob 앱/보상형 광고단위와 UMP 설정.
- Cloudflare SSV 서비스 배포 승인/도메인/비밀 및 운영범위.
- Firebase 분석·오류수집 설정과 개인정보/연령 정책.
- 아트 생성/가공 도구 또는 배포권한 있는 원본.

미설정은 코드부터 진행하지 말라는 뜻이 아니다. 해당 런타임·출시 항목을 차단으로 분리하고 가능한 기능을 구현한다.

## 인계 문서 검사
`reports/handoff_manifest_check.json`은 새 implementation_plan의 JSON 문법, 단계ID/선행관계,50마리·주택수,미착수표기의 내부 일관성만 검사한 기록이다.
이번 단계에서는 기존 장기 시뮬레이터,51개 저장참고검사,Unity 빌드,실광고를 재실행하지 않았다. 과거 검사수는 과거 보고서의 값으로 보존한다.
현재 작업 컨테이너의 public git clone은 DNS 오류로 실패했다. 네이티브 GitHub 읽기/쓰기 경로를 사용했다. 이를 사용자의 Mac 환경 문제로 해석하지 않는다.

## 에이전트가 갱신할 양식
각 단계마다 소스commit/도구버전/실행명령/종료코드/성공·실패·스킵/증거경로/미해결 외부작업을 추가한다. 상태를 바꿀 때 implementation_plan과 이 표를 함께 갱신한다.
작업 도중 'pass'를 먼저 쓰고 나중에 시험하지 않는다. 기기 접근이 없으면 NOT_RUN/BLOCKED를 그대로 남긴다.
