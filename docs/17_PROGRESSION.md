# Progression — v1.0 Working Spec
## Target Pace
첫 세션 Lv1→2/1→5마리, Day1 Lv2~3/5~8, Day2~3 Lv3~4/8~12, Day4~7 Lv4~6/12~23, Week2 Lv6~8/23~37, Week3 Lv8~9/37~44, Week3~5 Lv9→10/44→50. 테스트 후 조정.

## Center Upgrade Axes
주민 수, 마을 발전도, 주민 숙련, 골드의 4축을 사용한다. 특정 건물 하나의 최대 레벨을 강제하는 조건은 최소화.

## Village Development Score
소비 재화가 아닌 진행 점수. 건물 건설/업그레이드, 공원 개선, 일부 꾸미기 등으로 증가.

## Working Requirements
Lv2 주민3
Lv3 주민5+발전도50
Lv4 주민8+발전도150
Lv5 주민12+발전도350+숙련25×1
Lv6 주민15+발전도650+숙련25×2
Lv7 주민21+발전도1000+숙련25×4
Lv8 주민28+발전도1500+숙련50×3
Lv9 주민35+발전도2200+숙련50×6
Lv10 주민43+발전도3000+숙련75×3
골드 요구량은 경제 테스트 후 결정.

## Final
센터 Lv10에서 50마리까지 구조 가능. 센터 Lv10과 50/50 수집은 별도 최종 목표.
마을축제: 센터 Lv10 + 50/50 + 최종 발전도 + 주요 시설 건설. 모든 건물 Max는 필수 아님.
친밀도/관계는 메인 Progression Gate로 사용하지 않는다.
