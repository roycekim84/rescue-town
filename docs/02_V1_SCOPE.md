# v1.0 Scope

## Hard Boundary
**첫 출시는 시골 마을 하나까지만 제작한다.**

지역 이동, 두 번째 지역, 도시/항구/설원/섬 등은 v1.0 범위 밖이다. 현재 단계에서는 후속 지역의 세부 기획도 하지 않는다.

코드와 데이터는 향후 확장을 막지 않는 정도로 구성하되 미래 콘텐츠를 선제 구현하지 않는다.

## Start
- 빈 땅에 가까운 작은 시골 마을
- 낡은 구조소
- 플레이어
- 첫 구조 대상

## Progression
**구조 → 주민 증가 → 업무 자동화 → 주택/생활·상업 시설 → 주민 관계와 생활 → 시골 마을 완성**

## Completion
마을 발전 목표를 달성하면 **마을 축제**로 첫 완주를 보여준다. 이후에도 구조, 주민 관찰, 관계, 도감, 시설 개선, 경제 운영은 계속 가능하다.

## Out of Scope
- 지역 이동
- Prestige식 마을 초기화
- PvP/대규모 멀티플레이
- 복잡한 전투
- 여러 지역 동시 운영
- 과도한 다중 재화
