# Building Level Specification — v1.0 Working Spec
## Common
Max Lv10: Lv1 기본, Lv3 직원2+1차 변화, Lv6 직원3+2차 변화, Lv10 완성형.
Max Lv5: Lv1 직원1, Lv3 직원2+외형 변화, Lv5 직원3+완성형.
중간 레벨은 효율 성장일 수 있고 마일스톤은 눈에 보이는 변화를 준다.

## Buildings
- 구조센터 Lv10: 메인 진행. 주민 상한 3/5/8/12/17/23/30/37/44/50. 직원은 Lv2/3/5에서 1/2/3.
- 농장 Lv10: 활동/집중. Lv3 직원2, Lv6 직원3, Lv10 완성형.
- 카페 Lv10: 친화/감각. Lv3 직원2, Lv6 직원3/테라스, Lv10 완성형.
- 식당 Lv10: 친화/활동. 농장/어시장 공급 연계.
- 주택 Lv5: 직원 없음. 한 채에 여러 주민 거주. 구조 상한은 결정하지 않음.
- 어시장 Lv5: 활동/친화.
- 잡화점 Lv5: 친화/집중. Shopping 행동 제공.
- 공방 Lv5: 감각/집중. 인테리어 제작 허브.
- 미용실 Lv5: 감각/친화. 영구 외형 변경은 v1 제외.
- 진료소 Lv5: 돌봄/집중. 질병 관리 페널티는 v1 제외.
- 빵집 Lv5: 감각/친화. 농장 공급 연계.
- 공원 Lv5: 직원 없음. 생활 행동 확장.
- 마을광장 Lv5: 직원 없음. 후반 교류/이벤트 및 최종 축제 장소.

주민회관은 구조센터와 역할이 중복되어 v1.0 목록에서 제외.

한 주민은 동시에 한 직원 건물에만 정식 배치. 배치 변경은 무료이며 과거 숙련은 유지한다.
