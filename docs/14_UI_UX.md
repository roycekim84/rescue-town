# UI / UX — v1.0 Detail
- 앱 기본 화면은 살아 움직이는 세로형 마을.
- 상단 정보는 구조센터 레벨/골드 등 최소화.
- 고양이 터치: 이름, 직업, 현재 행동, 프로필, 따라가기.
- 건물 터치: Bottom Sheet로 수익/공급, 직원, 업그레이드, 꾸미기.
- 주민 프로필: 성격, 5능력, 직업, 숙련, 친밀도, 관계, 집, 구조/생활 기록.
- 직원 배치는 터치 기반이며 추천 배치/적합도/예상 효율 제공.
- 구조 신호는 월드 안에서 자연스럽게 표시.
- 도감은 50칸이며 미발견은 실루엣+힌트, 발견 후 실제 주민 프로필과 연결.
- 구조센터 화면은 다음 확장 조건과 보상을 보여주는 메인 목표 역할.
- 주민 목록은 전체/근무/자유 필터, 검색, 프로필, 월드 찾아가기 지원.
- 기능 해금과 함께 UI도 단계적으로 노출한다.
- 긴 설명 튜토리얼보다 실제 첫 구조/첫 배치로 학습시킨다.
