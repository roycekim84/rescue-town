Lv.2에서는 센터 이외 건물이 없고 센터 자체는 발전도 제외인데, Lv.3 진입이 발전도50을 요구했다.
또한 13종 중 센터를 뺀12종을 모두 끝까지 올려도, 종류별 한 번 산정 시 최대1,885점이다.

## 그 밖의 검사
- 최초1,000G ≥ 센터2/3+주택+공원 비용900G.
- 직원0이면 영업 수입0, 기본 지원금2G/분은 유지.
- 동일 능력 직원1/2/3마리 기여가1 / 1.7 / 2.2. UI 순서와 무관.
- 카페Lv.3 예시16.497G/분.

- 숙련 요구 인원은 이전 단계의 배치 가능 슬롯/정원을 넘지 않음.
- 공급 참조와13개 건물 경제 항목 일치.
- 경험치와 오프라인 보상에 광고 배율을 중복 적용하지 않는 설정.
- 기준 비용/시간 배열 길이와 비음수·단조 증가, 최종 정원50 확인.

## 아직 남은 검증
1. 50마리의 primaryCondition 문자열을 실행 가능한 조건으로 확장하고 실제 획득 경로를 검증.
2. home/square 같은 선호 시설 별칭과 housing/town_square 정식 ID 정규화.
3. 스태프·동물 능력 분포/성격 편향. 이번 검증은 고양이 개별 밸런스 감사가 아니다.
4. 공급 분배 수치 통합, 성장/공사 완료가 섞인 오프라인 시간 적분.

6. 저장/복귀/광고 보상 원장/실제 SDK/기기 성능 테스트.
7. 주택의 실제 필지 수·거주 정원·외형 배치. 발전도는 반복 주택 수와 독립적이다.
