## 참고 코드의 정확한 범위
persistence_reference.py는 전체 게임 저장구조의 작은 부분집합이다. 지급키/정원/영수증/보상 상태전이와 단일DB 커밋을 예시한다.
`reward_evidence` 입력은 이미 신뢰된 어댑터가 증거를 정규화했다고 가정한다. 문자열 source='verified_ssv'가 실제 검증을 수행하는 것이 아니다.
실제 클라이언트가 임의로 호출할 수 있게 노출하지 않는다. HTTP/암호서명/SDK/동의 게이트는 구현하지 않았다.
건설 start 명령의 비용·자격도 실제 엔진의 신뢰된 기획 계산층에서 산출해야 한다. 참고 모형에는 전체 건물/카탈로그 자격검사까지 재구현하지 않았다.
오프라인 적분은 주어진 수익 변화를 정확 산술로 계산한다. 전체50마리의 성장·생산공급·공사완료를 이 모듈로 시뮬레이션한 결과는 아니다.
