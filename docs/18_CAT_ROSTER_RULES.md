# Cat Roster Rules — v1.0
## Fixed Goal
도감 50종 = 실제 주민 50마리. 중복 구조 없음. 구조한 주민은 방출/해고/사망 등으로 영구 소실되지 않는다.

## Identity
각 고양이는 고정 Catalog ID와 기본 캐릭터 정체성을 갖는다. 기본 이름은 로컬라이징 가능하고 플레이어가 주민 이름을 변경할 수 있다.

## No Rarity
N/R/SR/SSR 등의 희귀도/티어는 없다. 발견 조건이 늦거나 까다로워도 더 강한 캐릭터가 아니다.

## Abilities
초기 5능력은 기본적으로 2~8 범위에서 개성에 맞게 설정한다. 특정 능력 편중과 명백한 상위호환을 피한다.

## Discovery Pool — working baseline
센터별 누적 발견 가능 수: Lv1 3 / Lv2 6 / Lv3 10 / Lv4 15 / Lv5 21 / Lv6 27 / Lv7 33 / Lv8 39 / Lv9 44 / Lv10 50.
센터 레벨은 자동 지급이 아니라 발견 가능 조건을 연다.

발견 조건은 건물, 게임 내 시간/환경, 주민 수, 생활 상황 등을 활용한다. 미발견 도감에는 추론 가능한 힌트를 주고 후반에는 힌트를 구체화할 수 있다.

## Appearance
현실 고양이 기반의 다양한 믹스/털 패턴을 중심으로 한다. 색만 바꾼 복제가 되지 않도록 얼굴 무늬, 털 길이, 눈, 귀, 꼬리, 양말 무늬 등을 활용한다.
