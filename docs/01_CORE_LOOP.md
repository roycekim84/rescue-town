# Core Loop

## Primary Loop
**탐색 → 구조 → 돌봄 → 정착 → 생활/직업 → 생산·소비 → 마을 성장 → 새로운 구조**

### 탐색/구조
시골 마을 주변에서 짧은 구조 상황을 발견하고 동물을 구조한다.

### 돌봄
배고픔, 위생, 안정, 건강 등을 회복한다. 초반에는 직접 수행하고 진행에 따라 자동화한다.

### 정착
회복한 동물이 주민이 되어 집과 직업을 갖고 시설을 이용하며 관계를 만든다.

### 생산·소비/성장
주민과 건물이 마을 경제를 움직이고 건설, 개선, 인테리어, 자동화가 열린다.

## Automation Loop
**직접 행동 → 반복 경험 → 자동화 해금 → 주민 배치 → 효율 개선 → 더 큰 의사결정**

자동화가 진행돼도 관찰, 배치, 성장 선택은 남아 있어야 한다.
