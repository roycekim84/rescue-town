# Buildings & Main Progression — v1.0 Detail

## Main Building: Rescue Center
구조센터는 v1.0의 메인 건물이자 전체 진행 척도다.

구조센터 레벨이 결정하는 것:
1. 구조/보유 가능한 고양이 수
2. 일반 건물의 현재 레벨 제한
3. 신규 건물/시스템 해금
4. 구조센터 자체 기능/외형

일반 건물의 현재 레벨 제한 기본식:
**min(건물 자체 Max Level, 구조센터 Level)**

구조센터 Max Level은 10.

### Population Curve — working baseline
Lv1 3 / Lv2 5 / Lv3 8 / Lv4 12 / Lv5 17 / Lv6 23 / Lv7 30 / Lv8 37 / Lv9 44 / Lv10 50

정확한 경제 수치는 밸런스 단계에서 조정할 수 있으나 v1.0 최종 상한 50은 고정한다.

## Center Progression
- Lv1: 구조/직접 돌봄
- Lv2: 첫 직원 배치와 자동화
- Lv3: 주택/공원, 주민 정착
- Lv4: 농장/어시장, 생산과 숙련
- Lv5: 카페, 소비/교류
- Lv6: 식당/잡화점, 생산-소비 연결
- Lv7: 공방/인테리어
- Lv8: 미용실/진료소, 전문 생활 서비스
- Lv9: 빵집/마을광장
- Lv10: 50마리, 최종 마을 발전, 축제 준비

구조센터 레벨업은 골드만으로 하지 않는다. 주민 수, 건물 총 성장, 숙련 주민 등 자연스러운 플레이 목표와 비용을 조합한다. 모든 건물을 현재 최대치까지 올려야만 진행되는 강제 구조는 피한다.

## Staff Rule
직원이 필요한 건물은 **최대 3마리**까지만 배치 가능하다.

레벨에 따라 직원 슬롯이 1 → 2 → 3으로 해금된다. 최대 슬롯을 모두 채우지 않아도 정상 운영 가능해야 한다.

기본안:
- Max Lv5 건물: Lv1 1명 / Lv3 2명 / Lv5 3명
- Max Lv10 건물: Lv1 1명 / Lv3 2명 / Lv6 3명

구조센터는 튜토리얼을 위해 Lv1 직원 0, Lv2 1, Lv3 2, Lv5 3을 기본안으로 한다.

## Building Level Types
건물별 최대 레벨은 5 또는 10.

중요 마일스톤에서는 단순 수치 상승이 아니라 외형/용량/기능/직원 슬롯 등의 실제 변화가 보여야 한다.

## Housing
구조센터가 총 주민 상한을 결정한다. 주택은 별도의 구조 가능 상한을 만들지 않는다.

주택은 실제 거주지, 생활 품질, 마을 연출을 담당한다. 집이 없는 정착 주민은 구조센터 임시 숙소를 사용할 수 있으며 주택 배정 시 생활 만족/연출이 개선된다.

## Building Work
직원 건물은 실제 배치 주민이 작업하는 모습을 보여준다. 건물별로 여러 작업 포인트/애니메이션을 마련한다.

건물은 경제 시설인 동시에 주민의 능력 및 직업 숙련을 키우는 육성 장소다.

## v1 Completion
구조센터 Lv10만으로 엔딩이 되지는 않는다. 50/50 수집, 핵심 마을 발전 조건 등을 만족한 뒤 마을 축제로 첫 완주를 연다.
