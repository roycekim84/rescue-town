# 첫 30분 플레이 명세 v0.1

상태: **상세기획 기준안 / 데이터·참조모형 검사 완료 / 실제 플레이 시간·엔진 구현 미검증**.
기준 커밋: `2154d5a27a26210e93fe5c2a67e118ad17ca4582`.
기계판독 데이터: `data/onboarding.json`. 경제·센터 비용·정원은 기존 JSON을 그대로 참조한다.

## 1. 이번 단계의 목표
첫 누적 플레이 20~30분 안에 구조 → 돌봄 → 첫 자동화 → 주택·공원 → 첫 생산시설 → 실제 영업수입을 한 번 경험하게 한다.
30분은 설계 목표이지 제한시간/매일 출석/해금 조건이 아니다. 관찰하느라 느려져도 실패하지 않는다.
센터 Lv.4, 주민 8마리, 주택·공원 각 1개, 농장 또는 어시장 1개가 권장 도착 모습이다.
50마리 수집·센터10·전체 시골마을·광고 포함 완결 출시라는 최종 범위는 줄이지 않는다.

앞선 35번 문서의 5,500G 최초지급 실험과 이번 **1,000G 최초 + 4,500G 단계 지급**은 서로 다른 안이다.
이번 안으로 전체 31.5일 완주가 재현됐다고 주장하지 않는다. 35번 결과는 당시 입력 그대로 보존한다.

## 2. 처음부터 5,500G를 한꺼번에 주지 않는다
운영 지원금은 '고양이 한 마리의 가격'이 아니라 시설을 마련하는 일회성 마을 정비 지원이다.

| 지급 조건 | 금액 | 다음 경험 |
|---|---:|---|
| 새 저장 최초 생성 | 1,000G | 기존 경제 기본값. 센터2·3 준비 |
| 센터2 이상에서 첫 정식 구조센터 직원 배치 | 600G | 정착 시설을 마련할 여유 |
| 첫 주택과 공원 모두 완성 | 2,900G | 센터4 확장비를 마련 |
| 센터4 확장 완료 | 1,000G | 농장 또는 어시장 첫 건설 |
| 합계 | **5,500G** | 시작 1,000G 포함, 추가 지급은 **4,500G** |

골드·조건·공사 완료는 기존 규칙을 지킨다. 조건 달성 시 자동 지급하고 작은 지원 알림을 보여준다.
'보상 받기' 버튼을 놓쳐서 멈추게 하지 않는다. 코치마크를 건너뛰어도 지급 조건은 유지한다.
`v1_initial_grant`를 재발행하거나, 기존 5,500G 비교 실험 위에 4,500G를 다시 더하지 않는다.

### 수익을 한 푼도 기다리지 않는 비용 검산
| 단계 | 변동 | 잔액 |
|---|---:|---:|
| 시작 | +1,000 | 1,000 |
| 센터2 | -100 | 900 |
| 첫 센터 직원 배치 | +600 | 1,500 |
| 센터3 | -300 | 1,200 |
| 주택1 | -200 | 1,000 |
| 공원1 | -300 | 700 |
| 정착시설 지원 | +2,900 | 3,600 |
| 센터4 | -3,000 | 600 |
| 생산시설 지원 | +1,000 | 1,600 |
| 농장1 선택 | -1,000 | **600** |
| 또는 어시장1 선택 | -1,200 | **400** |

주택50점 + 공원50점 = 발전도100으로 센터4의 점수 조건도 충족한다.
위 계산은 지원금2G/분, 광고, 영업수입을 모두 제외한 보수적인 **지출 경로 검산**이다.
모든 임의 지출을 허용해도 30분이 보장된다는 뜻은 아니다.
첫 영업 개시까지만 선택 구매를 센터 확장·첫 주택·공원·첫 생산시설 한 곳으로 한정한다.
추가 주택·선택 업그레이드는 첫 수입 이후 바로 공개한다. 관찰·이름 변경·무료 배치 실험은 계속 가능하다.

## 3. 실제 플레이 순서
| 누적 플레이 목표 | 행동 | 플레이어가 알게 될 것 |
|---|---|---|
| 0~2분 | 망고 발견, 먹이 유도, 기본 돌봄 | 내가 구조한 고양이가 이곳에 남는다 |
| 2~5분 | 구름·탄이 구조, 서로 다른 짧은 만남 | 같은 고양이 복제가 아니라 각자 다른 주민 |
| 5~8분 | 센터2, 주민1명 구조센터 배치, 나비·호두 돌봄 | 내가 하던 급식을 구조했던 고양이가 돕는다 |
| 8~12분 | 센터3, 첫 주택·공원, 지원금 | 구조소가 마을로 바뀐다 |
| 12~20분 | 두부·보리·모카, 산책·프로필·따라가기 | 8마리는 카드가 아니라 마을 속 실제 개체 |
| 20~23분 | 주민8·발전도100·3,000G 충족 후 센터4 | 센터가 다음 건물과 주민 상한을 연다 |
| 23~27분 | 농장/어시장 선택, 직원1명 배치, 실제 영업수입 | 주민 배치가 마을 자금과 숙련으로 이어진다 |
| 27~30분 | 일하는 주민 확인, 다음 목표, 자유 운영 | 다음은 다른 시설과 센터5·카페 |

시간은 목표 창이다. UI 읽기·길찾기·실기기 성능을 측정한 결과가 아니다. 숙련 수치 상승을 기다리는 강제 단계는 없다.
첫 고양이를 생산시설로 옮기는 선택을 제안할 수 있지만 특정 주민을 강제하지 않는다.
예: 망고를 농장으로 옮기고 구름을 돌봄 직원으로 배치. 과거 숙련과 외형은 그대로다.
권장 화면은 돌봄1 + 첫 생산1 + 자유6마리지만, 이 직업 조합 자체가 완료 조건은 아니다.

## 4. 첫 8마리는 추첨하지 않는다
초기 8마리는 CAT_001~008 순으로 기회를 제공한다. 획득 연출을 완료해야 주민이 되며 자동 무료 카드 지급은 아니다.
정원 예약은 구조 신호 선택 시 시작하고, 돌봄 대기 개체도 포함한다. 한 번에 구조 작업 하나.
센터1: 3마리 → 센터2: 5마리 → 센터3: 8마리. 센터4 이후 12마리 상한은 유지한다.
다른 초기 고양이는 삭제하지 않고 첫 생산시설 영업 이후 정상 발견 풀로 넘긴다.

- #001 망고: 센터 옆 상자, 먹이 유도.
- #002 구름: 센터 풀밭, 천천히 접근.
- #003 탄이: 상자 더미, 길 열어주기.
- #004 나비: 센터 마당에서 기존 주민을 따라온다. 카페/공원은 요구하지 않는다.
- #005 호두: 센터 급식 구역의 냄새를 따라온다. 어시장/식당은 요구하지 않는다.
- #006 두부: 공원 Lv.1 주변. 친밀도·관계 수는 요구하지 않는다.
- #007 보리: **배경 장소인 농로**. 아직 해금되지 않은 농장 건물을 요구하지 않는다.
- #008 모카: **배경 장소인 빈집**. 주택 고레벨·공방·현실 밤은 요구하지 않는다.

배경 장소는 시골 마을 안의 구조 지점이다. 별도 지역 이동/맵 콘텐츠를 추가하지 않는다.
구조 이벤트에 주민이 등장하면 보유한 실제 Resident ID를 사용한다. 생활 애니메이션이 우연히 발생해야만 발견되는 조건은 없다.

### 초기 타이머 초안
첫3마리 탐색 대기0초, 이후 탐색30/30/45/60/60초.
기본 돌봄은45/30/30/60/60/90/90/90초의 작업 목표를 둔다.
먹이·청결·안정에 대한 간단한 지시 이후 돌봄 진행이 시작한다. 첫 배치는 급식 반복을 돕고 다른 행동은 수동 대체 가능하다.
짧은 구조 상호작용은15~30초를 제작 목표로 둔다. 그 수치가 실제 완주 시간 검증을 대신하지 않는다.
진행 중 탐색·돌봄·공사는 비접속 중에도 시간이 흐르지만 다음 고양이를 무한 자동 수령하지 않는다.
완료된 신호/돌봄 결과는 사라지지 않는다. 접속 후 확인하면 이어서 진행한다.

## 5. 첫 영업은 진짜 경제로 처리한다
농장 또는 어시장을 선택한다. 농장을 추천하되 어시장을 골라도 같은 흐름으로 진행한다.
건설비는 원래 값, 직원은 최소1명. 첫 확인에서는 Lv.1이면 충분하다.
경제 원장에서 해당 배치 건물의 정상 영업수입이 누적1G 이상 발생하면 `first_business_started`를 기록한다.
기본 지원금·튜토리얼 지원·광고 수입은 이 조건에 포함하지 않는다.
일하는 애니메이션 종료 콜백이나 연출용 +100G로 조건을 대신하지 않는다.
고양이/카메라가 화면 밖이어도 정상 경제 수입이 있었다면 완료할 수 있다.
완료 후 선택 업그레이드·나머지 구조 신호를 공개하고 다음 목표를 제안한다.

## 6. 광고는 첫 경험을 가로막지 않는다
초기에는 광고 버튼·전면광고·광고 시청 튜토리얼을 노출하지 않는다.
보상형 제안 자격은 **첫 실제 영업 완료 AND 누적 실제 플레이20분 이상**이다.
그 뒤에도 현재 유용한 보상이 있을 때만 표시한다. 자격 충족 즉시 광고창을 띄우지 않는다.
누적20분은 광고 노출의 최소 안전 구간이지 게임 진행을 막는 타이머가 아니다.
첫 생산 전에 종료했다 돌아와도 기본 오프라인 수익은 정상 지급한다. 광고 자격이 없었다고 기본 보상을 잃지 않는다.
그때 숨긴 추가 광고 보상을 나중에 팝업 여러 개로 쌓아두지 않는다. 자격 충족 후 다음 유효 정산부터 선택하게 한다.
광고 없이 위의 모든 초기 과정을 진행할 수 있다.

## 7. 중단·복귀·스킵 계약
튜토리얼은 대사 페이지 번호보다 실제 월드 사실을 기준으로 이어간다.

- 정식 배치 이력, 완료한 건물, 구조/돌봄 단계, 예약한 Catalog ID, 공사ID, 지급한 지원ID를 저장한다.
- '닫기/스킵'은 설명만 건너뛴다. 고양이8마리·센터4·지원금 전액을 즉시 지급하지 않는다.
- 지급ID와 골드를 같은 영속 트랜잭션으로 반영한다. 재실행/재진입/중복 이벤트로 재지급하지 않는다.
- 누락된 알림은 저장된 건물·배치 이력으로 대조해 미지급 지원만 한 번 지급한다.
- 이미 지급받은 뒤 직원을 바꿔도 보상을 회수하거나 다시 주지 않는다.
- 기존 진행 저장은 지갑·주민·숙련을 보존하고 최초1,000G를 새로 주지 않는다.
- 도착 연출이 화면 밖이었다고 CAT_001을 복제하지 않는다. ID별 구조 예약과 정착은 한 번뿐이다.

이것은 런타임 요구사항이다. 참고 Python 모형의 체크포인트 복원이 실기기 강제종료의 원자성을 검증한 것은 아니다.

## 8. 구현 인수 기준
1. 광고·결제·기본 분당지원금에 의존하지 않고 첫 생산까지 지출 가능.
2. 센터3 이전 돌봄 완료 고양이는 임시숙소 주민으로 집계되어 정착 해금 순환잠금이 없음.
3. 8마리 모두 구조→돌봄→배치/산책에서 동일 개체와 외형.
4. 농장/어시장 어느 선택도 정원·발전도·돈 조건으로 막히지 않음.
5. 돈 버는 장면은 기존 실제 경제 계산이고 숙련 경험도 배치 이력에서 누적.
6. 중단·재접속·설명 스킵·중복 완료 이벤트에서 보상과 주민이 복제되지 않음.
7. 실제 첫 생산 시간, 단계별 체류 시간, 이탈/도움 요청은 이후 엔진 테스트에서 측정.
8. 상세 분석 이벤트에는 사용자 지정 이름 같은 자유 입력값을 넣지 않고 단계ID와 게임 상태만 사용.

## 9. 이번에 하지 않은 것
실제 이미지/스프라이트 생성, 엔진 구현, 광고 SDK 연결, 전체50마리 조건식 완성, 신규 분할지급안의 장기 완주 재시뮬레이션은 하지 않는다.
다음 작업은 나머지42마리의 실행 가능한 발견조건과 전체50마리의 순환잠금 검증이다.
