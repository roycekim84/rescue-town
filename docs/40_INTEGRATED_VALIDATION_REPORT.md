## 재현
실행기와 테스트는 이번에는 Git tools/에 포함한다. 기존 v0.1 실행기가 업로드되지 않았다는 과거 기록은 그대로 보존하되 새 통합기는 별개다.
현재 저장소 원본 입력으로 실행:

```sh
python3 -S tools/simulate_integrated_progression.py --include-events
python3 -S tools/test_integrated_progression.py
python3 -S tools/simulate_integrated_progression.py --case integrated_2_noads --case integrated_4_ads --offline-step 1 --output reports/integrated_convergence_1min.json
```

Git에는 결과요약을 기록한다. 전체 약정상태/구매/구조/광고 이벤트 결과와 당시 계산 투영 입력은 대화 ZIP에 함께 제공한다.
ZIP을 별도 폴더에 풀고 당시 입력으로 실행:

```sh
python3 -S tools/simulate_integrated_progression.py --snapshot --include-events
python3 -S tools/test_integrated_progression.py --snapshot
```

--snapshot은 ZIP의 reports/integrated_source_projection.json을 사용한다. 그 파일을 게임 data/에 덮어쓰지 않는다.
발견조건 보조 파일은 고정 blob SHA 검사로 다른 버전이 섞이지 않게 한다. Git 원본에서 --snapshot을 쓰려면 ZIP의 해당 reports/파일이 필요하다. 기본 명령에는 이 파일이 필요 없다.
전체 이벤트 결과 없이 테스트하면 계약32개만 실행되고 결과 재생6개는 스킵된다.38개 재현에는 먼저 --include-events 실행이 필요하다.
시뮬레이터를 다시 실행하면 해당 출력과 요약을 재작성하므로 변경 전 결과를 보존하려면 --output으로 다른 파일명을 준다.
