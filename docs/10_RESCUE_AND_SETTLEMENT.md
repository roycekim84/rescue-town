# Rescue & Settlement — v1.0 Detail

## Loop
**구조 신호 → 현장 확인 → 짧은 구조 행동 → 구조센터 → 돌봄 → 안정 → 정착**

## Discovery
v1.0은 별도 지역 이동/월드맵을 만들지 않는다. 시골 마을과 주변의 재사용 가능한 구조 장소에서 이벤트가 발생한다.

발견 조건은 다양할 수 있다:
- 구조센터 진행
- 특정 건물 건설/레벨
- 주민 수
- 주민 관계/생활 조건
- 게임 내 시간/환경

발견하기 어렵다고 강한 고양이는 아니다. 희귀도/SSR 등급은 사용하지 않는다.

도감의 미발견 고양이는 추론 가능한 힌트를 제공하여 외부 공략 없이는 찾기 어려운 구조를 피한다.

## Rescue Interaction
50회 동일 반복을 피하기 위해 짧은 구조 패턴을 여러 종류 사용한다.

후보:
- 먹이로 유도
- 장애물 치우기
- 높은 곳에서 내려오게 하기
- 흔적/소리 찾기
- 기다리며 신뢰 형성

목표 플레이 시간은 대체로 짧게 유지한다. 실패가 해당 고양이의 영구 소실로 이어지지 않는다.

## Care
구조 직후 주요 돌봄 상태 기본안:
- 배고픔
- 안정
- 청결

초반에는 플레이어가 직접 돌보고, 구조센터와 직원이 성장하면서 반복 돌봄은 자동화한다.

고양이 성격에 따라 돌봄 반응이 다를 수 있으며 돌봄 과정에서 성격/선호 정보를 발견할 수 있다.

## Settlement
돌봄 조건을 만족하면 고양이가 Rescue Town 주민으로 정착한다.

정착 시:
- 동일 Resident ID/외형 유지
- 기본 이름 유지 또는 플레이어가 이름 변경 가능
- 자유 주민으로 시작
- 주택이 있으면 거주지 배정 가능
- 필요할 때 건물 직원으로 배치 가능

## Capacity
구조센터의 현재 레벨이 주민 상한을 결정한다. 상한 도달 시 플레이어에게 구조를 거부하도록 강요하기보다 신규 구조 신호의 발생을 대기시키는 방향을 사용한다.

## Advertising Boundary
구조 성공 여부와 동물의 안전을 광고 시청에 걸지 않는다.

보상형 광고는 탐색/대기 시간 단축 같은 선택적 편의에만 연결할 수 있다.
