# Rescue System

## Purpose
구조는 캐릭터 획득 수단이면서 Rescue Town의 정체성을 전달하는 콘텐츠다.

## Flow
**탐색/신호 발견 → 짧은 구조 상황 → 구조 성공 → 보호소 돌봄 → 회복 → 주민 정착**

## Rescue Scenes
짧고 다양한 상황을 사용한다.
- 폐창고의 울음소리
- 상자 속 동물
- 나무에서 내려오지 못하는 동물
- 가게 앞을 떠나지 않는 동물

긴 스토리보다 짧은 상호작용과 기억할 만한 맥락을 목표로 한다.

## History
구조 장소, 상황, 시점 등은 주민 기록으로 남길 수 있다. 훗날 직업과 생활로 이어져 플레이어의 개인적인 마을 역사가 된다.

## v1.0 Animals
종류와 수는 아직 확정하지 않는다. 과도한 종 수보다 주민 행동과 개성을 먼저 검증한다.
